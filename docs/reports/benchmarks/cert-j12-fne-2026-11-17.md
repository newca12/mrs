# CASC-J12 FNE campaign and strict re-audit (2026-11-17)

> The 75-row FNE campaign produced **46 raw `Theorem` answers**. Its original
> strict audit reported 9 `VerifiedGood` and 37 `Unknown`; 36 of those Unknowns
> were missing-`Axioms/` include errors caused by the audit child replacing
> `TPTP` with the selected-problem directory. After commit `637f396` removed that
> override, the first replay of the same run and problem-corpus digests under
> local TPTP v10.0.0 reported 40/46 `VerifiedGood` and left `LCL660+1.005`
> `Unknown`. A kernel definition-fold ordering fix now certifies that proof; the
> final replay reports **41/46 `VerifiedGood`, 5 `Unknown`, and 0 `VerifiedBad`**.
> This is not an exact J12 v9.0.0 re-audit or a canonical CASC score: the
> producer tree was dirty, its host had 54,198 MB effective memory against the
> 131,072 MB allowance, and the replay used a local TPTP-v10.0.0 tree that the
> audit identity does not hash.

## `LCL660+1.005` c162: overlapping definition folds

The failing node is:

```text
cnf(c162, plain,
    def_main_25(X42, X43, X47, X48) |
    def_main_26(X52, X53, X56, X57, X58, X61, X64, X65, X66, X69, X70, X71, X75, X76, X77, X78),
    inference(cnf_transformation, ..., [c7, c34, c25, c23, c28, c27, c26,
                                        c24, c32, c30, c29, c31, c33, c22, c21, c20])).
```

The relevant definition parents overlap. `c28` defines `def_main_20`; its body
matches a smaller block inside `c21`'s `def_main_13` body. `c33` defines
`def_main_25` in terms of `def_main_13`. The old source fold iterated match
modes outside the citation-ordered definitions. During the `Permuting` pass it
tried `c28` before `c21`; `def_main_20` could then abbreviate the inner overlap
inside `def_main_13`'s source block. That hid the larger match, so `def_main_13`
and its dependent `def_main_25` remained unmatched. The CNF expansion could
find `c162`'s clause, but the kernel correctly refused to certify while a cited
definition had not been accounted for.

The working fix in `crates/mrs-proof-kernel/src/lib.rs` folds definitions named
by the goal first, traverses their cited-definition dependencies in body order,
and tries all four match modes for each definition before moving to the next.
It then tries a per-definition citation-order pass and the old mode-major
citation-order pass as bounded compatibility fallbacks. The all-cited-definitions
soundness guard remains in place. Regression test
`folds_goal_definition_before_overlapping_subformula_definition` covers both
goal-first folding and the citation-order fallback with the residue fast path
disabled.

## Comparability

The November 13 full J12 run also recorded 46 raw FNE theorems; 45 are common
to the November 17 set. `NUN068+1` appears only in the November 17 run, while
`SYO604+1` appears only in the November 13 run. This is an unpaired raw-status
comparison, not a schedule effect: the producer commits and binaries differ,
the adapters differ (`mrs` versus `mrs-starexec`), both producer trees were
dirty, and the November 17 host had substantially less memory. An exploratory
sum of per-problem times on the 45 common solves was 1,036.256 s versus 379.147 s
(an apparent 2.73x reduction); it must not be presented as a measured speedup
or causal portfolio effect.

`MRS_HARDWARE=casc` configured eight workers and a 131,072 MB memory allowance,
but it does not pin the process to eight cores. This host had 16 physical cores
and 63,763 MB RAM; the prover reported 54,198 MB effective memory and
`mem_unrepresentable=1`. The run therefore did not provide the full CASC memory
allowance and is not a canonical eight-core CASC measurement.
