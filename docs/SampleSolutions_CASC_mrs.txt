Notes for the organizer
------------------------

mrs is entered in FOF and UEQ only (withdrawn from FNT — no
finite-model-building component). No non-obvious features requiring
further explanation; both proofs are standard CNF refutations produced
by the given-clause loop, run with the full 8-way parallel strategy
portfolio (`--schedule casc_ueq` for BOO001-1; default `casc` schedule
for SEU140+2). The `file(<path>, <name>)` annotation gives the actual
local filesystem path the problem was read from and the axiom/lemma
name from the original problem file; at competition time the real
StarExec sandbox path is used here instead, via the same code path.

Both proofs contain a few duplicate axiom leaves under different clause
IDs (e.g. `ternary_multiply_1` appears as both c2153 and c2, and
`associativity` as both c2148 and c2152, in the BOO001-1 proof). This is
expected and harmless: mrs runs several strategies in parallel and
shares derived unit equalities across them to accelerate sibling
searches; when a shared clause (and its full justifying ancestor chain)
is spliced into a receiving strategy's own clause store, its ancestors
are assigned fresh local clause IDs, which can duplicate an axiom the
receiving strategy also independently holds under its own original ID.
Every clause in both proofs, including the spliced-in ancestors, carries
a complete and locally self-consistent derivation back to the original
problem's axioms/conjecture — no clause anywhere in either proof has an
empty or dangling parent list.
